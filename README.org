> Pipeline I implemented for my Bachelor thesis. Summary: the paper 'Poincaré Embeddings for Learning Hierarchical Representations' mentions that their model can approximate hierarchies even if the data representing it is partially corrupted. This assumption was not tested, which is what we did. We went a bit too far: this pipeline is practically a framework to customize how you want to test this hypothesis by controlling and tweaking the original dataset, corrupting it, and then reconstructing the embedded tree from it. The whole thing is modular and can be extended as one wishes to. :)
